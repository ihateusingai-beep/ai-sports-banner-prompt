# AI運動會 Banner 提詞器

將軍澳培智學校 · 獅子會姊妹學校計劃「AI運動會」Banner 設計比賽用提詞工具。

## Live
https://ihateusingai-beep.github.io/ai-sports-banner-prompt/

## 功能（P0）
1. 教學 3 屏（可跳過）
2. 8 步圖卡 wizard（emoji）
3. 自訂文字欄
4. 繁 / 簡 / EN prompt + Negative + 複製
